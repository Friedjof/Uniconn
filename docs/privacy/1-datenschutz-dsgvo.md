# 📄 1. Datenschutz (DSGVO)

| Thema                         | Umsetzung in Uniconn                                             |
|------------------------------|------------------------------------------------------------------|
| Datenminimierung             | Nur notwendige Daten (E-Mail, Apartment, optionaler Nickname)   |
| Zweckbindung                 | Nutzung ausschließlich zur internen Kommunikation               |
| Datenexport                  | Selbstbedienung über UI (JSON)                                  |
| Recht auf Löschung           | „Account löschen“-Funktion (Soft-Delete + optionaler Delay)     |
| Verarbeitungsverzeichnis     | Dokumentiert in interner Admin-Policy                           |
| Keine Drittanbieter-Weitergabe | Keine externen Tracker, kein Cloud-Processing (on-prem möglich) |
| AV-Vertrag                   | Optional für Instanzbetreiber                                   |
