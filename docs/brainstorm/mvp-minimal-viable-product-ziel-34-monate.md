# 🚀 MVP – Minimal Viable Product (Ziel: 3–4 Monate)

## Funktionen
- Benutzerregistrierung & E-Mail-Verifikation
- Physischer Code zum Apartment-Abgleich
- Apartment-basierte Chats (anonym/offen)
- Community: einfache Posts + Votes + Moderation
- Admin-/Moderator-Panel: Rollen, Meldungen
- Datenschutzfunktionen (DSGVO-konform)

## Technik
- Next.js + REST API + JWT + Prisma/PostgreSQL
- Dockerized Deployment mit Watchtower
- Static File Handling via Reverse Proxy
