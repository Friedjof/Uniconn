# 📰 E3: Community Board

## Story 3.1 – Beitrag posten
Als Bewohnerin  
möchte ich einen Beitrag verfassen,  
damit ich Informationen oder Meinungen teilen kann.

## Story 3.2 – Markdown nutzen
Als Nutzerin  
möchte ich Beiträge mit Markdown formatieren,  
damit ich Inhalte übersichtlicher präsentieren kann.

## Story 3.3 – Up-/Downvotes
Als Bewohner  
möchte ich Beiträge bewerten können,  
damit relevante Inhalte sichtbar werden.

## Story 3.4 – Beitrag melden
Als Community-Mitglied  
möchte ich Beiträge melden können,  
damit Moderatoren bei Verstößen benachrichtigt werden.
