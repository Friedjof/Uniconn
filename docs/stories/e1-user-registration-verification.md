# ✅ E1: User Registration & Verification

## Story 1.1 – Registrierung
Als neue Bewohnerin  
möchte ich mich mit E-Mail, Name und Passwort registrieren können,  
damit ich die Plattform nutzen kann.

## Story 1.2 – E-Mail-Verifikation
Als registrierte Nutzerin  
möchte ich meine E-Mail durch einen Code bestätigen,  
damit mein Account aktiviert wird.

## Story 1.3 – Apartmentauswahl
Als Nutzerin nach der Registrierung  
möchte ich mein Apartment aus einer Liste auswählen,  
damit ich dem richtigen Chat zugeordnet werde.

## Story 1.4 – Verifikationscode
Als Bewohnerin  
möchte ich einen Code aus meinem Briefkasten eingeben können,  
damit meine Identität gegenüber Moderatoren bestätigt ist.
