## 🧰 Tech Stack

- **Frontend**: Next.js, Tailwind CSS, Zustand (State Management)
- **Backend**: Node.js mit Fastify oder Express
- **Auth**: JWT (Access/Refresh), speakeasy für TOTP
- **DB**: Prisma ORM auf SQLite/PostgreSQL
- **Realtime**: socket.io, eigene Channels je Wohnung
- **Tests**: Vitest (Frontend), Jest/Supertest (Backend)
