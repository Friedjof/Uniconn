# 🔧 Stack-Übersicht

| Bereich               | Technologie                                 |
|----------------------|---------------------------------------------|
| Frontend             | Next.js (TypeScript, SPA mit SSR)           |
| Backend/API          | REST-API (Express oder Fastify)             |
| Auth                 | JWT + TOTP (speakeasy / otplib)             |
| DB                   | SQLite (Dev), PostgreSQL (Prod)             |
| ORM                  | Prisma                                       |
| Realtime             | WebSockets (socket.io oder ws)              |
| Deployment           | Docker + Docker Compose                     |
| CI/CD                | GitHub Actions                              |
| Updates              | Watchtower                                  |
| Media Delivery       | Nginx Static Hosting + Proxy                |
| Monitoring (optional)| Sentry, Logflare, Grafana                   |
