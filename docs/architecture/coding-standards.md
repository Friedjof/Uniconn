## 📐 Coding Standards

- **TypeScript only**: Strict-Modus aktiviert
- **Linting**: ESLint (Airbnb-konform), Prettier enforced
- **Naming Conventions**: camelCase für Variablen, PascalCase für Komponenten, snake_case für DB
- **Folder-Naming**: kebab-case (z. B. `user-profile`)
- **Testabdeckung**: Mindestens 80 % für kritische Module
