# 🔐 1. Authentication & Verification

- Registrierung mit E-Mail, Name, Passwort  
- E-Mail-Verifizierung mit Token  
- Login mit JWT  
- Zwei-Faktor-Authentifizierung (TOTP optional)  
- Auswahl des Apartments (Dropdown mit Suche)  
- Code-basierte Verifikation (nur einmal gültig, expiring)  
- Rollenmanagement (User, Verified, Mod, Admin, Superadmin)  
- Passwort-Zurücksetzen via E-Mail
