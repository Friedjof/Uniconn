# 🌐 6. Frontend- & UI-Verhalten

- SPA (Next.js mit SSR, Zustand erhalten bei Refresh)  
- Mobile-first Design  
- Theme-Auswahl: Dark, Light, System  
- Barrierefreiheit (z. B. Tastatur-Navigation, Alt-Texte)  
- Multilinguale Oberfläche (mind. Englisch, später DE)  
- Einstellungsseite pro Nutzer (Nickname, Sprache, Benachrichtigungen)
