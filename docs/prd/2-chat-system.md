# 💬 2. Chat-System

- Live-Chat pro Apartment → Channels heißen wie `B015`  
- Chat ist **sichtbar für alle Bewohner dieses Apartments**  
- Optionaler anonymisierter Modus  
- Markdown-Unterstützung (fett, kursiv, Codeblöcke)  
- Lesebestätigungen & Typing-Status (via WebSocket)  
- Meldung einzelner Nachrichten durch Nutzer  
- Moderation von Chatinhalten (Soft-Delete durch Mods)  
- Avatar & Nickname-Anzeige, kein Zwang zur Klarnamenanzeige
