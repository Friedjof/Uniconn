# 👥 Organisatorische Risiken

| Risiko                                          | Auswirkung                             | Mögliche Maßnahme                         |
|------------------------------------------------|-----------------------------------------|-------------------------------------------|
| Keine Moderatoren aktiv im System              | Verifikationen & Meldungen bleiben liegen | Backup-Moderatoren festlegen              |
| Physische Codes werden missbraucht             | Falsche Verifikation                    | Code-Rotation, Logs, Codes verfallen lassen|
| Sprachliche Barriere (nur Englisch)            | App wird nicht genutzt                 | Deutsch als Option (später einführen)     |
| App wird zu groß, verliert Fokussierung        | Nutzer verlassen App                   | MVP-Strategie, Feature-Freeze ab Release  |
